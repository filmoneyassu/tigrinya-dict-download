# Tigrinya Dict · ትግርኛ ዲክት

Type Tigrinya phonetically in every app on your Mac or Windows PC.

## Download

- **Mac** (macOS 14 or later): [TigrinyaDict.dmg](https://github.com/filmoneyassu/tigrinya-dict-download/releases/latest/download/TigrinyaDict.dmg)
- **Windows** (10 or 11): [TigrinyaDict-Setup.exe](https://github.com/filmoneyassu/tigrinya-dict-download/releases/latest/download/TigrinyaDict-Setup.exe)

## Install

**Mac:** open the .dmg, double-click **Install Tigrinya Dict**. Then System Settings → Keyboard → Text Input → Edit… → + → Tigrinya → **ትግርኛ ዲክት** → Add.

**Windows:** run the installer. If Windows says "Windows protected your PC", click **More info → Run anyway**. Then press Win + Space and choose **ትግርኛ ዲክት**.

Type `selam` → ሰላም. The letter stays underlined while you can still change it (k → ክ, ki → ኪ, kie → ኬ).
